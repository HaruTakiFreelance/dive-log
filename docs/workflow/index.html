Dive Log Book
How to Use
ダイビングログの記録から公開まで
v1.3  ·  Updated 2026-06-25
1
RECORD YOUR DIVE Mac必要
ダイビング当日、ローカルアプリから記録フォームを開いて潜水データを入力します。
日付・場所・ポイント・開始〜終了時刻・深度・ウェイト・見た魚などを登録すると、Notion に自動保存されます。
天気・波高は Open-Meteo から自動取得されます。
ローカルアプリを開く →
↓
2
ADD FISH TO ENCYCLOPEDIA Mac必要
ローカルアプリの記録フォームで魚を検索し、未登録の場合は「新しい魚を登録」ボタンから追加できます。
魚名を入力して「図鑑から取得」を押すと、shiny-ace.com から英名・学名・分類（目・科・属）・生息域・レア度・人気・撮りやすさを自動入力します。
ローカルアプリへ →
↓
3
UPLOAD PHOTOS & VIDEOS Mac必要
帰宅後、Mac の「記録する」ボタン（http://localhost:5001）からローカルアプリにアクセスして写真・動画をアップロードします。
HEIC は自動で JPEG に変換され、縦1280px にリサイズして docs/photos/ に保存されます。動画（MP4・MOV）はそのまま保存されます。
写真アップロードへ →
↓
4
BUILD LOGBOOK Mac必要
Notion のデータと写真を元に、静的 HTML のログブックを生成します。
ローカルアプリのホーム画面（localhost:5001）から「ログブックを生成」を押すだけです。
毎回全件再生成します（Notion API 使用、AI は不使用）。
ローカルアプリへ →

生成物: docs/index.html · sessions/ · fish.html · workflow/

↓
5
PUBLISH TO GITHUB PAGES Mac必要
ローカルアプリのホーム画面から「Push して公開」を押すと、docs/ を git push して自動でウェブ公開されます。
ログブックを見る →
All Features
🤿
ダイブ記録
日付・場所・ポイント・時刻・深度・ウェイト・見た魚・コスト・コメント・動画リンクを Notion に保存
● Mac（localhost:5001）
🐠
魚図鑑
登録済み魚を一覧・フィルタ・検索。カードをタップで詳細（英名・学名・分類・生息域・レア度など）を表示
● スマホ・PC どこでも可
✨
魚情報自動取得
shiny-ace.com をスクレイプして英名・学名・目・科・属・生息域・レア度・人気・撮りやすさを自動入力
● Mac（localhost:5001）
📷
写真・動画アップロード
HEIC→JPEG 変換・縦1280pxリサイズを自動実行。動画（MP4/MOV）はそのまま保存。キャプション付き
● Mac（localhost:5001）
🌤
天気・波高の自動取得
ダイブ記録保存時に Open-Meteo API から気象・海況データを自動取得してログに記録
● スマホ・PC どこでも可
📖
ログブック生成
Notion の全データから静的 HTML を生成。ホーム・セッション詳細・スライダー・魚図鑑を一括出力（AI 不使用）
● Mac（localhost:5001）
🚀
GitHub Pages 公開
ローカルアプリの Push ボタン1つで docs/ を git push、GitHub Pages に自動デプロイ
● Mac（localhost:5001）
🎬
動画スライダー
セッションページの写真・YouTube 動画をスワイプで閲覧。ドット表示で現在位置を確認
● スマホ・PC どこでも可
