Dive Log Book
How to Use
ダイビングログの記録から公開まで
1
RECORD YOUR DIVE どこでも可
ダイビング当日、スマホやPCから記録フォームを開いて潜水データを入力します。
日付・場所・時刻・深度・見た魚を登録すると、Notionデータベースに自動で保存されます。
記録フォームを開く →
↓
2
UPLOAD PHOTOS Mac必要
帰宅後、Macでローカルアプリを起動して写真・動画をアップロードします。
HEIC は自動で JPEG に変換され、縦1280pxにリサイズして保存されます。
cd "/Users/harutakizawa/Desktop/claude code/dive-log" python3 app.py

起動後 → http://localhost:5001/photo でアップロード

↓
3
BUILD LOGBOOK Mac必要
Notionのデータと写真を元に、静的HTMLのログブックを生成します。
ローカルアプリのホーム画面から「ログブックを生成」ボタンを押すか、ターミナルで実行します。
python3 scripts/build_logbook.py

docs/ フォルダに index.html・セッションページ・魚図鑑が生成されます

↓
4
PUBLISH TO GITHUB PAGES Mac必要
生成した docs/ フォルダを GitHub にプッシュすると、自動でウェブ公開されます。
cd "/Users/harutakizawa/Desktop/claude code/dive-log" git add docs/ git commit -m "update logbook" git push
ログブックを見る →
